# Randomness 2.1I Amendments

## Authority

This file records the approved 2.1I Random additions and supersedes conflicting older statements in `07 - Randomness.md` that say Character Features are Random-excluded.

## Skin Condition

Skin Condition remains a manual multi-select. Random chooses exactly one approved Skin Condition from the existing condition list. Individual conditions use standard 25 / +5 item decay and lifetime counters.

## Character Features

Character Features remains a manual multi-select. Random chooses exactly one approved Character Feature from the existing feature list. Individual features use standard 25 / +5 item decay and lifetime counters.

Pregnancy is not a Character Feature. `Very Pregnant` belongs to Physical Appearance and is manual-only.

## Props

Props remains a manual multi-select with a maximum of three manual Props. Random chooses exactly one eligible Prop from one flat pool across all Prop categories. Individual Props use standard 25 / +5 item decay and lifetime counters.

## Locations

Normal Location Random continues to use the existing Location policy.

Two additional Random subsets are approved:

- Random Indoor: only records marked `indoor` or `indoor-exterior-view` are eligible.
- Random Outdoor: only records marked `outdoor` are eligible.

For a subset draw, only top-level Location groups containing at least one eligible record participate. Those participating groups are equal Random buckets. Individual Location decay remains shared with normal Location Random.
