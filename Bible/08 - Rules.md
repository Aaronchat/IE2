# Rules

## Tattoo Visibility

Tattoos may be prompted only on body regions that remain fully uncovered after the complete outfit is assembled.

| Final coverage | Tattoo allowed |
| --- | --- |
| Uncovered | Yes |
| Partially covered | No |
| Covered | No |

- Partial coverage remains useful clothing data, but it counts as covered when determining tattoo placement.
- Any clothing layer that covers or partially covers a region blocks tattoo prompting for that region.
- Sheer, lace, and mesh garments block tattoos by default because image models may render tattoos through the fabric.
- The engine must not mention a tattoo beneath leggings, tights, sleeves, dresses, or other covering garments.
- For an already selected Tattoo, blocked required regions cause that Tattoo to be omitted; the engine must not relocate, substitute, or reroll it.
- More precise body regions may be added later instead of weakening this rule.

This intentionally sacrifices some partially visible tattoos to prevent tattoos from bleeding through clothing or appearing as fabric prints.
